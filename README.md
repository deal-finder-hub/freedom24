# Freedom24 multilingual guides – flat GitHub Pages structure

This repository contains `index.html` and **50 standalone language guides**, all in the **repository root**. No language subfolders are needed.

Examples: `freedom24-de.html`, `freedom24-fr.html`, `freedom24-es.html`.

The homepage language tiles link to these HTML files. Canonical URLs, hreflang references and sitemap.xml point to the same flat filenames.

Upload all files directly to the root of the existing `freedom24` GitHub repository. Remove old language folders after checking deployment.

**Note:** The promotional maximum of $800 per gift share is not a guaranteed benefit. Check current Freedom24 offer terms, codes and country eligibility before publishing.


## Updated step-by-step WELCOME instructions
The English homepage and 50 guides include a numbered workflow and deposit-tier table. The deposit tiers and ability to combine codes have **not** been independently verified. Major-language guides include new full 10-step localized instructions; some regional/minority-language guides reuse existing localized copy in the expanded workflow and require native-speaker editorial review before publication.
